# Bare Metal AVR C/C++ Template 📟

**Disclaimer:** Repository currently under development.

A minimalistic template for developing bare metal applications for AVR microcontrollers using C/C++ and CMake. This template is designed to help you get started quickly with AVR development without relying on the Arduino framework.
